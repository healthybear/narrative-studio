# 页面8：素材库 (/library)

**核心价值**：从分析到创作的知识沉淀，将优秀片段、叙事技巧积累为可复用的素材库。

**布局**：
- 左侧：分类导航树
- 右侧：素材卡片列表
- 顶部：搜索栏 + 筛选器

**功能**：

1. **素材收藏（在所有标注页面中）**：
   - 在任何标注页面选中文本后，右键菜单新增"⭐ 收藏为素材"
   - 弹出对话框：
     - 素材类型：情节设计、人物塑造、情感渲染、视角运用、语言风格、结构技巧（多选）
     - 叙事模式：下拉选择预置模式或自定义
     - 笔记：为什么好？学到了什么？
     - 标签：自由标签（如 #反转 #悬念 #伏笔）
     - 评分：1-5星

2. **分类导航**：
   - 📖 按类型：情节设计、人物塑造、情感渲染、视角运用、语言风格、结构技巧
   - 🎭 按叙事模式：欲扬先抑、伏笔回收、双线叙事、悬念营造、情感爆发等
   - 🏷️ 按标签：#反转、#悬念、#冲突、#成长等
   - 📚 按来源作品：显示所有分析过的作品
   - ⭐ 按评分：5星、4星、3星等

3. **素材卡片展示**：
   - 标题（用户自定义或自动生成）
   - 来源：作品名 - 章节 - 场景
   - 类型标签 + 叙事模式标签
   - 文本片段（可展开查看完整上下文）
   - 用户笔记（为什么好、学到了什么）
   - 关键要点（提取的核心技巧）
   - 标签云
   - 评分 + 收藏时间
   - 操作：编辑、删除、应用到创作

4. **搜索与筛选**：
   - 全文搜索（标题、内容、笔记）
   - 多维度筛选（类型、模式、标签、来源、评分）
   - 排序：按时间、按评分、按相关度

5. **叙事模式管理**：
   - 预置模式库（20+常见叙事模式）
   - 用户自定义模式：
     - 模式名称
     - 模式描述
     - 关键要素
     - 参考案例（关联素材）
   - 模式可视化（知识图谱）

6. **批量操作**：
   - 批量打标签
   - 批量导出（Markdown/JSON）
   - 批量删除

**交互**：
- 点击素材卡片查看详情
- 拖拽素材到"创作工作区"（Phase 6功能）
- 双击素材跳转到原始场景
- 右键菜单：编辑、删除、复制、分享

**技术实现**：
- 前端：Naive UI卡片 + 虚拟滚动
- 存储：IndexedDB（本地）+ 可选云端同步
- 搜索：Fuse.js模糊搜索
