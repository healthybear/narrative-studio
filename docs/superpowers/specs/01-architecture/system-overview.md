## 概述

Narrative Studio 采用三层架构设计，实现前端本地优先、后端轻量化、NLP 服务独立部署的架构模式。

**核心设计理念**：
- 🎯 **本地优先**：前端使用 IndexedDB 存储数据，离线可用
- 🚀 **AI 优先**：80% 自动标注，20% 人工审核
- 🔌 **松耦合**：三层独立部署，接口清晰
- 📈 **渐进增强**：从纯前端到全栈逐步演进

## 2. 分层设计

### 2.1 前端层（Nuxt 3）

**职责**：
- 用户界面渲染
- 用户交互处理
- 本地数据管理（IndexedDB）
- API 请求封装
- 状态管理

**技术选型**：
- **框架**：Nuxt 3（Vue 3 全栈框架）
- **语言**：TypeScript（类型安全）
- **UI 组件库**：Naive UI（Vue 3 组件库）
- **状态管理**：Pinia（Vue 3 官方状态管理）
- **数据存储**：IndexedDB（通过 localforage 封装）
- **可视化**：ECharts、D3.js
- **工具库**：VueUse、mammoth、nanoid、date-fns

**核心模块**：
```
apps/web/
├── pages/              # 8个核心页面
├── components/         # 可复用组件
├── composables/        # 组合式函数
├── stores/             # Pinia 状态管理
├── utils/              # 工具函数
├── services/           # API 客户端
└── db/                 # IndexedDB 封装
```

### 2.2 API 层（Fastify）

**职责**：
- 用户认证与授权
- 云端备份管理
- 项目元数据同步
- NLP 请求转发
- 错误处理与降级

**技术选型**：
- **框架**：Fastify（高性能 Node.js 框架）
- **语言**：TypeScript
- **数据库**：PostgreSQL（用户数据、备份数据）
- **认证**：JWT（JSON Web Token）
- **日志**：Pino（Fastify 内置）

**核心模块**：
```
apps/api/
├── routes/             # 路由定义
│   ├── auth.ts         # 用户认证
│   ├── backup.ts       # 云端备份
│   ├── novels.ts       # 项目元数据
│   └── nlp.ts          # NLP 请求转发
├── services/           # 业务逻辑
├── plugins/            # Fastify 插件
├── utils/              # 工具函数
└── db/                 # 数据库连接
```

### 2.3 NLP 层（Python）

**职责**：
- 场景拆分（无监督学习）
- 事件检测（主动学习）
- 人物识别（NER + 共指消解）
- 情感分析（预训练模型）
- 视角分析（规则 + 统计）

**技术选型**：
- **语言**：Python 3.10+

- **NLP 库**：spaCy、transformers、NLTK
- **模型**：BERT、GPT（情感分析、事件检测）
- **机器学习**：scikit-learn（主动学习）

**核心模块**：
```
apps/nlp/

├── services/           # NLP 服务
│   ├── scene_splitter.py
│   ├── event_detector.py
```

## 3. 核心设计原则

### 3.1 本地优先（Local-First）

**设计理念**：
- 前端使用 IndexedDB 存储所有数据
- 离线可用，无需网络连接
- 云端备份作为可选功能
- 数据所有权归用户

**优势**：
- ✅ 快速响应（无网络延迟）
- ✅ 隐私保护（数据不离开本地）
- ✅ 离线可用（无需网络）
- ✅ 降低服务器成本

### 3.2 AI 优先（AI-First）

**设计理念**：
- AI 自动完成 80% 的标注工作
- 用户只需审核和修正（20% 工作量）
- 通过主动学习持续提升准确率

**工作流程**：
1. **AI 自动标注**：场景拆分、事件检测、人物识别等
2. **置信度标记**：绿色（高）、黄色（中）、红色（低）
3. **用户审核**：优先审核低置信度结果
4. **批量确认**：一键确认高置信度结果
5. **迭代优化**：用户反馈用于模型优化

**准确率目标**：
- 场景拆分：85%+（无监督学习）
- 事件检测：85%+（主动学习 2-3 轮）
- 人物识别：90%+（NER + 共指消解）
- 情感分析：85%+（预训练模型）
- 视角分析：90%+（规则 + 统计）

### 3.3 松耦合（Loose Coupling）

**设计理念**：
- 三层独立部署，接口清晰
- 前端可独立运行（纯前端模式）
- API 层可选（云端功能）
- NLP 层可替换（支持不同模型）

**接口设计**：
- 前端 ↔ Fastify：HTTP REST API
- Fastify ↔ Python NLP：HTTP REST API
- 统一错误处理和降级策略

### 3.4 渐进增强（Progressive Enhancement）

**演进路径**：
1. **Phase 1**：纯前端应用（IndexedDB + 静态部署）
2. **Phase 2**：添加 Fastify API（用户认证 + 云端备份）
3. **Phase 3**：集成 Python NLP（AI 自动标注）
4. **Phase 4**：AI 生成功能（智能创作辅助）

## 4. 技术选型理由

### 4.1 为什么选择 Nuxt 3？

- ✅ **Vue 3 生态**：组合式 API、TypeScript 支持
- ✅ **SSR/SSG**：支持服务端渲染和静态生成
- ✅ **文件路由**：自动路由生成
- ✅ **性能优化**：自动代码分割、懒加载
- ✅ **开发体验**：热重载、TypeScript、ESLint

### 4.2 为什么选择 Fastify？

- ✅ **高性能**：比 Express 快 2 倍
- ✅ **TypeScript 友好**：原生 TypeScript 支持
- ✅ **插件系统**：丰富的插件生态
- ✅ **Schema 验证**：内置 JSON Schema 验证
- ✅ **轻量级**：适合作为中间层

### 4.3 为什么选择 Python + spaCy？

- ✅ **NLP 生态**：丰富的 NLP 库和预训练模型
- ✅ **spaCy**：工业级 NLP 库，性能优秀
- ✅ **transformers**：Hugging Face 预训练模型
- ✅ **易于扩展**：支持自定义模型和管道

### 4.4 为什么选择 IndexedDB？

- ✅ **大容量**：支持 GB 级数据存储
- ✅ **结构化**：支持索引和查询
- ✅ **异步 API**：不阻塞主线程
- ✅ **浏览器原生**：无需额外依赖

## 6. 性能优化策略

### 6.1 前端优化

- **代码分割**：按页面和组件懒加载
- **虚拟滚动**：长列表使用虚拟滚动
- **Web Worker**：大文件解析在 Worker 中执行
- **IndexedDB 优化**：批量操作、索引优化
- **缓存策略**：Service Worker 缓存静态资源

### 6.2 API 层优化

- **连接池**：数据库连接池
- **缓存**：Redis 缓存热点数据
- **压缩**：Gzip/Brotli 压缩响应
- **限流**：防止 API 滥用

### 6.3 NLP 层优化

- **模型量化**：减小模型体积
- **批处理**：批量处理请求
- **GPU 加速**：使用 GPU 推理
- **模型缓存**：预加载常用模型

## 7. 安全设计

### 7.1 前端安全

- **XSS 防护**：Vue 3 自动转义
