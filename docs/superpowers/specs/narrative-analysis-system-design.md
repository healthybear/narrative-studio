# Narrative Studio - 叙事分析系统设计文档

**版本**：v1.1  
**最后更新**：2026-05-15  
**状态**：设计阶段

## 1. 项目概述

Narrative Studio 是一个基于计算叙事学的可视化小说创作与分析工具。

**核心功能**：
- 叙事结构分析：事件检测与建模、情感与人物建模、叙事视角计算
- 叙事生成与评估：AI辅助创作、叙事质量评估

## 2. 系统架构

### 2.1 技术栈
- **前端框架**：Nuxt 3 + Vue 3 + TypeScript
- **UI组件库**：Naive UI
- **工具库**：VueUse、localforage、mammoth、nanoid、date-fns
- **可视化**：ECharts、D3.js
- **数据存储**：IndexedDB（纯前端方案）
- **后端API**：Fastify + TypeScript
- **NLP分析**：Python + spaCy/transformers

### 2.2 开发流程
1. 数据采集阶段：结构标注（章节/场景拆分）
2. 叙事分析阶段：事件、人物、情感、视角标注
3. 可视化展示：多维度分析结果呈现
4. AI生成阶段：智能创作辅助（后续）

## 3. 页面设计

### 3.1 页面1：项目管理 (/novels)

**功能**：
- 小说列表展示（卡片式布局）
- 新建项目（支持文件上传 .txt/.docx 或直接粘贴文本）
- 项目信息展示：标题、作者、字数、创建时间、最后修改时间
- 操作：打开项目、删除项目、导出数据

**交互**：
- 点击卡片进入结构标注页面
- 新建按钮打开导入对话框
- 支持拖拽上传文件

### 3.2 页面2：结构标注 (/novel/:id/structure)

**布局**：
- 左侧：章节树形结构（可折叠）
- 中间：文本编辑区（章节/场景内容展示与编辑）
- 右侧：场景元数据编辑面板

**功能**：
- 章节识别：自动识别（正则匹配常见格式）+ 手动调整
- **场景拆分（AI优先）**：
  - 🤖 AI自动拆分（主题模型 + 段落聚类 + 时空检测）
  - 置信度标注（绿/黄/红）
  - 用户快速审核（确认/删除/调整边界）
- 场景元数据：时间、地点、出场人物、场景类型
- 章节重命名、排序、合并

**交互**：
- 点击左侧章节/场景切换中间显示内容
- AI自动拆分后，场景边界以彩色标记显示（绿=高置信度，黄=中，红=低）
- 中间区域支持选中段落后右键操作（拆分为新场景、合并到上一场景）
- 右侧面板实时保存元数据
- 批量操作：一键确认所有高置信度边界

### 3.3 页面3：事件标注 (/novel/:id/events)

**布局**：
- 左侧：场景列表（显示已标注事件数量 + AI置信度）
- 中间：场景文本 + 事件标注区域
- 右侧：事件详情编辑面板

**功能**：
- **事件标注（AI优先）**：
  - 🤖 AI自动检测事件（预训练模型/主动学习）
  - 置信度排序（低置信度优先审核）
  - 批量确认高置信度事件
- 事件类型：冲突、转折、高潮、伏笔、揭示、其他
- 事件属性：
  - 重要性评分（1-5星）
  - 涉及角色（多选）
  - 因果关系（关联其他事件）
  - 事件描述
- **主动学习模式**：
  - 用户标注5-10个样本
  - AI学习后自动标注全文
  - 迭代优化（2-3轮达到85%+准确率）

**交互**：
- 查看AI标注的事件列表（按置信度排序）
- 事件以彩色高亮显示在文本中（绿/黄/红）
- 批量操作：
  - ✓ 批量确认高置信度事件
  - ✗ 删除误报
  - ✏️ 修正事件类型/边界
  - ➕ 补充遗漏事件
- 拖拽连线建立事件因果关系

### 3.4 页面4：人物建模 (/novel/:id/characters)

**布局**：
- 左侧：人物列表（显示出场次数）
- 右侧：人物详情编辑区

**功能**：
- **人物识别（几乎全自动）**：
  - 🤖 NER自动提取所有人物（准确率90%+）
  - 共指消解识别别名
  - 自动统计出场频率
  - 用户只需合并重复、补充描述
- 人物基本信息：姓名、别名、描述、标签
- **人物关系（AI辅助）**：
  - 🤖 AI自动抽取关系
  - 关系类型（亲属、朋友、敌对、爱情、师徒等）
  - 关系强度（1-5）
  - 出现场景（关系建立/变化的场景）
  - 用户审核和调整强度
- 角色弧光追踪：
  - 关键场景标注
  - 性格/目标变化记录

**交互**：
- 查看AI提取的人物列表
- 简单操作：
  - 🔗 合并重复人物（拖拽合并）
  - ✏️ 补充人物描述
  - 🎚️ 调整关系强度
  - ➕ 添加遗漏人物（罕见）
- 关系图可视化（小型网络图预览）
- 拖拽连线建立人物关系

### 3.5 页面5：情感分析 (/novel/:id/emotions)

**布局**：
- 左侧：场景列表
- 中间：段落文本 + 情感标注
- 右侧：情感曲线预览

**功能**：
- **段落级情感标注（AI自动）**：
  - 🤖 预训练BERT模型自动分析全文（准确率85%+）
  - 情感倾向（-1到1，负面到正面）
  - 情感强度（0到1）
  - 情感类型（喜悦、悲伤、愤怒、恐惧、惊讶等，多选）
  - 置信度标注
- 实时情感曲线预览
- **用户审核模式**：
  - 重点审核极值点、突变点、异常点
  - 微调倾向和强度
  - 批量确认高置信度标注

**交互**：
- 查看自动生成的情感曲线
- 段落按置信度着色（绿/黄/红）
- 点击段落微调情感参数：
  - 滑块调整倾向和强度
  - 复选框选择情感类型
- 右侧曲线实时更新
- 批量操作：一键确认高置信度段落

### 3.6 页面6：叙事视角 (/novel/:id/perspective)

**布局**：
- 场景列表 + 视角标注面板

**功能**：
- **按场景标注视角类型（AI自动）**：
  - 🤖 规则+统计自动推断（准确率90%+）
  - 第一人称
  - 第三人称全知
  - 第三人称限知
- **聚焦人物标注（AI辅助）**：
  - 自动识别聚焦人物（第三人称限知时）
  - 用户确认或调整
- 叙事距离标注（近/中/远）
- 视角分布统计
- 视角转换识别
- **用户审核模式**：
  - 查看AI推断结果
  - 快速确认或修正
  - 指定聚焦人物

**交互**：
- 查看AI推断的视角分布
- 场景列表显示视角类型（带置信度）
- 简单操作：
  - ✓ 批量确认高置信度场景
  - ✏️ 修正个别场景
  - 👤 指定聚焦人物（下拉选择）
- 查看视角分布饼图和转换时间线

  2. 分角色情感曲线（多条线）
  3. 情感强度曲线
- 关键事件标注点
- 章节分界线
- 情感统计数据：
  - 平均情感值
  - 情感波动度

**交互功能**：

3. **节奏分析**：
   - 场景长度变化曲线
   - 节奏评分
   - 节奏建议

4. **叙事视角分布**：
   - 视角类型占比饼图
   - 视角转换时间线
   - 主要聚焦人物统计

5. **综合评估**：
   - 结构完整度评分
   - 情感饱满度评分
   - 人物立体度评分
   - 节奏合理性评分
   - 视角一致性评分
   - 总体评分

**功能**：
- 生成分析报告（Markdown/HTML）
- 导出PDF报告
- 对比分析（多部作品对比）

**技术实现**：ECharts多图表组合

**核心价值**：从分析到创作的知识沉淀，将优秀片段、叙事技巧积累为可复用的素材库。

- 左侧：分类导航树

   - 🎭 按叙事模式：欲扬先抑、伏笔回收、双线叙事、悬念营造、情感爆发等
   - 🏷️ 按标签：#反转、#悬念、#冲突、#成长等
   - 📚 按来源作品：显示所有分析过的作品
   - ⭐ 按评分：5星、4星、3星等

3. **素材卡片展示**：
   - 标题（用户自定义或自动生成）
   - 来源：作品名 - 章节 - 场景
   - 类型标签 + 叙事模式标签
   - 文本片段（可展开查看完整上下文）
   - 用户笔记（为什么好、学到了什么）
   - 关键要点（提取的核心技巧）
   - 标签云
   - 评分 + 收藏时间
   - 操作：编辑、删除、应用到创作

4. **搜索与筛选**：
   - 全文搜索（标题、内容、笔记）
   - 多维度筛选（类型、模式、标签、来源、评分）
   - 排序：按时间、按评分、按相关度

5. **叙事模式管理**：
   - 预置模式库（20+常见叙事模式）
   - 用户自定义模式：
     - 模式名称
     - 模式描述
     - 关键要素
     - 参考案例（关联素材）
   - 模式可视化（知识图谱）

6. **批量操作**：
   - 批量打标签
   - 批量导出（Markdown/JSON）
   - 批量删除

**交互**：
- 点击素材卡片查看详情
- 拖拽素材到"创作工作区"（Phase 6功能）
- 双击素材跳转到原始场景
- 右键菜单：编辑、删除、复制、分享

**技术实现**：
- 前端：Naive UI卡片 + 虚拟滚动
- 存储：IndexedDB（本地）+ 可选云端同步
- 搜索：Fuse.js模糊搜索

   - 人物识别


## 9. 智能标注策略

### 9.1 设计原则：AI优先，人工审核

**传统模式的问题**：
- 用户需要手动标注每个场景、事件、情感点
- 对于长篇小说（10万字+），工作量巨大
- 标注过程枯燥，容易出错

**改进模式**：
```
AI自动标注全文（1分钟）
    ↓
置信度评分
    ↓
├─ 高置信度（80%）：直接采用，无需审核
├─ 中置信度（15%）：快速审核，一键确认/修正
└─ 低置信度（5%）：仔细审核，手动调整
    ↓
用户反馈 → 模型持续学习 → 准确度提升
```

**工作量对比**：
- 传统模式：100%人工标注
- 改进模式：10-20%人工审核
- **效率提升：5-10倍**

### 9.2 场景拆分 - 无监督学习

**技术方案**：
1. **主题模型（LDA/BERTopic）**
   - 自动识别段落主题变化
   - 检测语义断裂点
   
2. **段落向量聚类**
   - 使用 Sentence-BERT 生成段落向量
   - DBSCAN/层次聚类识别场景边界
   
3. **时空标记检测（规则）**
   - 正则匹配时间词（"第二天"、"三年后"）
   - 地点词识别（"回到家"、"来到学校"）
   
4. **多信号融合**
   - 综合主题、语义、时空三种信号
   - 自动标注场景边界

**用户交互**：
- AI自动拆分场景（准确率约75-85%）
- 用户审核边界：
  - ✓ 确认正确
  - ✗ 删除错误边界
  - ➕ 添加遗漏边界
- 平均每10个场景需要调整2-3个

### 9.3 事件检测 - 半监督学习（主动学习）

**方案A：零样本学习（推荐）**
1. 使用预训练事件抽取模型
   - 中文模型：MAVEN-zh, DuEE
   - 多语言模型：XLM-RoBERTa fine-tuned on ACE
   
2. 定义事件类型映射
   - 预训练类型 → 叙事类型
   - 例：Conflict事件 → 冲突、Attack事件 → 冲突
   
3. 直接推理，无需标注
   - 准确率约70-80%
   - 召回率约60-70%

**方案B：主动学习（更高准确度）**
1. **初始标注**（5-10个样本）
   - 用户标注少量典型事件
   - 涵盖各种事件类型
   
2. **模型训练**
   - 基于BERT的序列标注模型
   - 使用少样本学习（Few-shot Learning）
   
3. **主动学习循环**
   ```
   while 准确度 < 目标阈值:
       模型预测全文事件
       计算预测置信度
       选择最不确定的10个样本
       用户标注这10个样本
       模型重新训练
   ```
   
4. **迭代2-3轮后**
   - 准确率可达85-90%
   - 用户总标注量：30-50个样本
   - 相比全文标注（可能200+事件），工作量减少80%

**用户交互**：
- 查看AI标注的事件列表
- 按置信度排序（低置信度优先审核）
- 批量操作：
  - ✓ 批量确认高置信度事件
  - ✗ 删除误报
  - ✏️ 修正事件类型/边界
  - ➕ 补充遗漏事件

### 9.4 人物建模 - 几乎全自动

**技术方案**：
1. **命名实体识别（NER）**
   - 使用预训练中文NER模型（spaCy, LAC, BERT-NER）
   - 自动提取所有人名
   - 准确率：90-95%
   
2. **共指消解**
   - 识别人物别名和代词指代
   - 例："张三" = "小张" = "他"
   - 工具：neuralcoref, fastcoref
   
3. **关系抽取**
   - 基于依存句法的规则
   - 预训练关系抽取模型
   - 自动识别：亲属、朋友、敌对等关系
   
4. **出场频率统计**
   - 自动统计每个人物的出场次数
   - 识别主要角色 vs 次要角色

**用户交互**：
- 查看AI提取的人物列表
- 简单操作：
  - 🔗 合并重复人物（"张三" + "小张"）
  - ✏️ 补充人物描述
  - 🎚️ 调整关系强度
  - ➕ 添加遗漏人物（罕见）
- 工作量：约5-10分钟（vs 传统30-60分钟）

### 9.5 情感分析 - 预训练模型直接推理

**技术方案**：
1. **预训练情感分析模型**
   - 中文BERT情感模型（RoBERTa-wwm, ERNIE）
   - 多分类：正面/负面/中性
   - 回归：情感倾向值（-1到1）
   
2. **情感强度计算**
   - 情感词密度
   - 情感词权重（程度副词加权）
   
3. **情感类型识别**
   - 细粒度情感分类模型
   - 识别：喜悦、悲伤、愤怒、恐惧、惊讶等
   
4. **段落级自动标注**
   - 批量处理全文段落
   - 生成情感曲线

**准确率**：
- 情感倾向：85-90%
- 情感强度：80-85%
- 情感类型：75-80%

**用户交互**：
- 查看自动生成的情感曲线
- 重点审核：
  - 极值点（最高/最低情感）
  - 突变点（情感急剧变化）
  - 异常点（与上下文不符）
- 微调操作：
  - 拖动滑块调整倾向/强度
  - 修改情感类型
- 工作量：约10-15分钟（vs 传统60-90分钟）

### 9.6 视角分析 - 规则+统计（几乎全自动）

**技术方案**：
1. **人称代词统计**
   - 统计"我"、"他"、"她"的出现频率
   - 准确率：接近100%
   
2. **心理动词检测**
   - 识别"想"、"觉得"、"认为"等心理动词
   - 判断是否进入人物内心
   
3. **视角类型推断**
   ```
   if "我" 占比 > 50%:
       视角 = 第一人称
   elif 存在多个人物的心理描写:
       视角 = 第三人称全知
   else:
       视角 = 第三人称限知
   ```
   
4. **聚焦人物识别**
   - 统计心理动词的主语
   - 识别主要聚焦人物

**准确率**：
- 视角类型：90-95%
- 聚焦人物：85-90%

**用户交互**：
- 查看AI推断的视角分布
- 简单确认：
  - ✓ 确认正确
  - ✏️ 修正个别场景
  - 👤 指定聚焦人物（第三人称限知）
- 工作量：约5分钟（vs 传统20-30分钟）

### 9.7 置信度可视化

**设计目标**：让用户快速识别需要审核的内容

**可视化方案**：
1. **颜色编码**
   - 🟢 绿色：高置信度（>0.8）- 可直接采用
   - 🟡 黄色：中置信度（0.5-0.8）- 建议审核
   - 🔴 红色：低置信度（<0.5）- 需要仔细检查
   
2. **置信度分数**
   - 每个标注项显示置信度百分比
   - 例：事件"主角遭遇危机" - 置信度 87%
   
3. **筛选功能**
   - 按置信度排序
   - 只显示低/中置信度项
   - 批量确认高置信度项

### 9.8 持续学习机制

**目标**：模型随用户使用而不断改进

**实现方案**：
1. **用户反馈收集**
   - 记录用户的修正操作
   - 确认/拒绝/修改 → 训练样本
   
2. **增量学习**
   - 定期（每100个反馈）重新训练模型
   - 使用用户反馈作为新训练数据
   
3. **个性化适应**
   - 学习用户的标注偏好
   - 例：用户倾向于标注更多细粒度事件
   
4. **模型版本管理**
   - 保存模型快照
   - 支持回滚到之前版本

### 9.9 工作量对比总结

| 任务 | 传统模式 | 智能模式 | 效率提升 |
|------|---------|---------|---------|

| 事件标注 | 60-120分钟 | 10-20分钟 | 6倍 |
| 人物建模 | 30-60分钟 | 5-10分钟 | 6倍 |
| 情感分析 | 60-90分钟 | 10-15分钟 | 6倍 |
