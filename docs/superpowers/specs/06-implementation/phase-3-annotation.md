# Phase 3：标注功能

**预计时间**：2 周  
**最后更新**：2026-06-06

---

## 目标

Phase 3 的目标是把 Narrative Studio 从“能导入和存储文本”，推进到“能围绕结构单元做手动标注”。

当前阶段的基本顺序是：

1. 场景拆分
2. 事件标注
3. 人物建模
4. 情感标注
5. 视角标注

其中**场景拆分是前置依赖**。后续事件、视角、情感等能力都应该以场景为最小操作单元。

---

## 当前实施策略

- **先手动，后自动**
  先做完整的手动标注闭环，再引入 AI 辅助

- **先本地，后服务**
  优先完成 IndexedDB 数据持久化，再接后端 / NLP 服务

- **先结构，后分析**
  场景是后续标注的基础，没有稳定场景就不要直接推进事件页和人物页

## 当前技术重点

### 场景拆分顺序

场景拆分按以下顺序推进：

1. 手动拆分、合并、保存
2. 场景元数据编辑
3. AI 建议预留

本轮不直接接入 NLP 场景切分服务。

### 文本与偏移

- 章节偏移相对于小说全文
- 场景偏移相对于章节内容
- 后续事件、情感、视角都建议挂在场景维度

---

## 交付标准

Phase 3 的最低可交付标准是：

- 用户可以围绕场景做结构级手动标注
- 标注结果可以正确存储和恢复
- UI 流程连贯，基本错误可恢复
- 为后续 AI 自动化接入预留稳定数据结构
